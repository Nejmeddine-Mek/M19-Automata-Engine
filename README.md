# UPGRADED Automata Simulator
 - This simulator is an evolution of the original Turing machine simulator
 it features now more simulators which include Turing Machines, Linear Bounded Automata, Push Down Automata and the Finite State Automata.
 - Unlike many simulators out there, that only build Automata through a graphical window, drag and drop states and transitions, our simulators feature a domain specific language for each automata type to write your automata as code rather than drawing them.
  
 ## Features
  - The app features configurable machines, so that you can configure the alphabet you want, the symbol you want to correspond to epsilon, as well as the symbols at the end of the stack in PDAs and tape ends in LBAs
  - It also utilizes a Domain Specific language for each automaton to write instructions, instead of graphically building the automaton which might take a lot of time and effort.
  - This approach should also help with thinking more algebraically rather then thinking graphically and visually.
  - The Turing Machine should be able to work as a computations turing machine seen in chapter one, or as an automaton
